P/01
GOV EDI FASTAPI WINDOWS RELAY TAILSCALE

한국 관세청 EDI
연동 시스템.

UNI-PASS · KCSAPI4.dll · GOVCBR830 · 자동 면장 발급

unipass-relay / api

KOREAN CUSTOMS SERVICE · LIVE
BACKGROUND

KCSAPI4.dll은 32-bit Windows 전용. 대부분의 현대 ERP·SaaS는 Linux 기반이라 직접 연동이 불가능합니다.

SOLUTION

Windows Relay Server + HTTP API + Tailscale 메시 VPN으로 Linux SaaS에서 면장 발급을 자동 호출합니다.

OUTCOME
  • KCS 테스트서버 C200 정상처리 달성
  • GOVCBR830 스키마 완전 검증
  • 수기 발급 작업 완전 제거
  • 관세청 S/W 개발자 등록 완료

분석 SaaS.

변화탐지 · 농경지 분석 · 자동 리포트 · 지도 기반 대시보드

위성영상은 한 장당 수 GB. 전문가 판독 의존도가 높아 비전문가가 활용할 수 있는 SaaS가 부재했습니다.

OUTCOME

06 FAQ

자주 묻는 질문들.

Q.01 어디까지 함께하나요? +

기획 정리, 정보 구조 설계, 프론트엔드·백엔드 개발, AI 모델 통합, 정부 EDI 연동, 인프라 구축, 운영 안정화까지 프로젝트 상황에 맞게.

Q.02 어떤 프로젝트와 잘 맞나요? +

AI 서비스 MVP, 운영 중 제품 AI 추가, OCR·문서 자동화, 정부 EDI·공공 API 연동, 산업 특화 SaaS 구축이 필요한 팀.

Q.03 AI 모델만 개발도 가능한가요? +

가능합니다. 다만 모델만 만들고 끝나기보다 실제 서비스 통합 단계까지 함께 가는 것을 권장합니다. 운영 환경에서 모델 성능을 유지하려면 데이터 수집·재학습 파이프라인이 함께 설계되어야 하기 때문입니다.

Q.04 정부 EDI나 공공 API 연동 경험이 있나요? +

네. 한국 관세청 EDI(UNI-PASS) 연동을 실제로 구축하여 상용까지 진행했습니다. S/W 개발자 등록 완료 및 테스트서버 C200 정상처리 검증 완료.
