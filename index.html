  • 관세청 S/W 개발자 등록 완료

Python 3.12 · KCSAPI4.dll · FastAPI · Windows Server · Tailscale · PostgreSQL · Docker

02 / Approach What we make

모델이 아닌, 제품을 만듭니다.

a. AI 서비스 구축 LLM · VLM · Computer Vision을 실제 서비스 플로우에 연결합니다. → b. 웹 · 앱 플랫폼 운영형 SaaS, 관리자 대시보드, 결제·회원·권한·정산 통합. → c. 업무 자동화 · 운영 도구 OCR · 문서 자동화, 데이터 파이프라인, 내부 관리 시스템. → d. Edge · Computer Vision 엣지 디바이스 기반 영상 분석 · 관제 · 온디바이스 추론. →
Best fit
  • 신규 AI 서비스 MVP를 빠르게 출시해야 하는 팀
  • 운영 중인 제품에 새 기능을 추가하려는 팀
  • 수기 입력·반복 업무가 많아 자동화가 필요한 조직
  • 정부 EDI·공공 API 연동이 필요한 산업 특화 비즈니스
  • 영상 분석·관제 시스템이 필요한 현장 운영 회사
  • 모델 개발자는 있지만 서비스화·운영툴이 부족한 팀

04 / FAQ Frequently asked

자주 묻는 질문.

Q · 01 어디까지 함께하나요?

기획 정리, 정보 구조 설계, 프론트엔드 · 백엔드 개발, AI 모델 통합, 정부 EDI 연동, 인프라 구축, 운영 안정화까지 프로젝트 상황에 맞게.

Q · 02 어떤 프로젝트와 잘 맞나요?

AI 서비스 MVP, 운영 중 제품의 새 기능 추가, OCR · 문서 자동화, 정부 EDI · 공공 API 연동, 산업 특화 SaaS 구축이 필요한 팀.

Q · 03 AI 모델만 개발도 가능한가요?

가능합니다. 다만 모델만 만들고 끝나기보다 실제 서비스 통합 단계까지 함께 가는 것을 권장합니다. 운영 환경에서 모델 성능을 유지하려면 데이터 수집·재학습 파이프라인이 함께 설계되어야 하기 때문입니다.

Q · 04 정부 EDI · 공공 API 연동 경험이 있나요?

네. 한국 관세청 EDI(UNI-PASS) 연동을 실제로 구축하여 상용까지 진행했습니다. S/W 개발자 등록 완료 및 테스트서버 C200 정상처리 검증 완료.
